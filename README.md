# 💣 Bomberman Multiplayer – Enhanced Version

A multiplayer online version of the classic Bomberman game, built in Java.

> **Credits:** This project is based on [Bomberman by ORIGINAL_AUTHOR](), originally made as a university project.

## 🎮 Features
- Online multiplayer
- Classic mechanics – place bombs, break blocks, defeat opponents
- Retro pixel-art graphics with sound
- Create or join game rooms

## 🧰 Tech Stack
Java · Java Swing · WebSockets · MySQL · Docker

## 🚀 How to Run
1. Start the database:
   ```bash
   docker compose down
   docker compose up -d
   ```
2. Run the game:
   ```bash
   chmod +x run.sh
   ./run.sh
   ```
